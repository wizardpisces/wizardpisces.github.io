前端开发

“A source map provides a way of mapping code within a compressed file back to it’s original position in a source file”

V3 spec example:

{
    version : 3,
    file: "out.js",
    sourceRoot : "",
    sources: ["foo.js", "bar.js"],
    names: ["src", "maps", "are", "fun"],
    mappings: "AAgBC,SAAQ,CAAEA"
}
