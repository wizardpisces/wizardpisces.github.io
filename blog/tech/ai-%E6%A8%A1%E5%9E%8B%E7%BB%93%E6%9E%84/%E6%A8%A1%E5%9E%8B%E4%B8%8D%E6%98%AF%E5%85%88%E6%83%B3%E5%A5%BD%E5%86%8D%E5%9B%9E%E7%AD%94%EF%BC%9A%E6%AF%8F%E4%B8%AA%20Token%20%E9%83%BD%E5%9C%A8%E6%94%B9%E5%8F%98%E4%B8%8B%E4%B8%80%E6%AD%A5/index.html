模型不是先想好再回答：每个 Token 都在改变下一步

大模型回答问题时，总是一个 Token 接一个 Token 地往外生成。

你按下停止，句子可能断在一半。重新问同一个问题，开头只换了几个字，后面的论证却走向完全不同的方向。

这不只是聊天界面的打字动画。

主流大模型通常不会先在内部写好整段答案，再逐字显示。它每一步只解决一个问题：

根据目前已经出现的内容，下一个 Token 最可能是什么？

Token 是模型处理文本的基本单位，可能是一个字、半个词、一个标点或一小段字符。更重要的是，每个刚生成的 Token 不只会显示给用户，也会立刻成为下一步的新输入。

回答就是这样一步步长出来的。

模型每次只往前走一小步

为了看清过程，假设一个极小的模型收到问题：

周末去哪里？

第一步，它没有一份已经写好的旅游建议，只有一组候选概率：

“如果”    42%
“建议”    35%
“可以”    23%

假设这次选中了“如果”。

输入随即从：

周末去哪里？

变成：

周末去哪里？如果

模型重新计算下一步：

“你”      48%
“喜欢”    30%
“预算”    22%

如果第一步选中的不是“如果”，而是“建议”，第二步看到的候选可能已经变成：

“去”      51%
“先”      27%
“选择”    22%

这些数字只是为了展示机制而简化的例子。关键不在具体概率，而在两次计算面对的输入已经不同。

第一个 Token 看起来只是一个开头，实际上已经改写了后面有哪些路可以走。

一个输出，为什么会变成下一步的条件

《代码定义结构，权重存储知识：一个例子看懂大模型如何推理》讲过：代码规定怎样计算，权重保存训练中学到的模式。

语言模型推理时，这些权重不会直接取出一条完整答案。它们根据当前序列，为下一个 Token 计算分数，再转换成概率。

生成三步，可以写成：

第 1 步：
根据 Prompt，选择 t1

第 2 步：
根据 Prompt + t1，选择 t2

第 3 步：
根据 Prompt + t1 + t2，选择 t3

对应的概率关系是：

P(t1, t2, t3 | Prompt)

= P(t1 | Prompt)
× P(t2 | Prompt, t1)
× P(t3 | Prompt, t1, t2)

每一步都依赖此前已经选中的结果。过去的选择改变未来还可能发生什么，这叫路径依赖。

当前输入
   ↓
下一个 Token 的概率
   ↓
选中一个 Token
   ↓
追加回当前输入
   ↓
重新计算下一步

直到模型生成结束标记，或者系统要求它停下。

创造力和跑偏，来自同一个地方

路径依赖让大模型不必从数据库里取出一条固定回答。

同一个开头可以继续成解释、故事、代码或反驳；只要早期选择不同，后面就可能展开成另一条完整路径。这是生成具有开放性的原因之一。

代价也来自这里。

假设模型在开头生成了一条没有依据的陈述：

这项研究发表于 2018 年……

这句话一旦进入当前序列，下一步预测面对的上下文里，就已经出现了“研究确实存在，而且发表于 2018 年”。

后面的 Token 更容易继续补出作者、期刊和实验结论。新内容未必更接近事实，却会越来越符合前面那条错误陈述。

模型不是先拿到一份错误答案，再把它完整念出来。错误也可能在生成过程中逐步长大：

一个错误开头
      ↓
成为下一步的输入
      ↓
后续内容与它保持连贯
      ↓
整段话越来越像真的

流畅只能说明后文接得上前文，不能证明最初那一步是对的。

为什么“先列计划”有时真的有用

让模型先列计划，并没有给它增加新的知识。

计划的作用，是先往上下文里写入一条更稳定的生成路径：

先确认问题
再列证据
最后给结论

后续 Token 都会在这条结构之后生成，比直接冲向结论更不容易漏步骤。

但路径稳定不等于方向正确。如果计划一开始就误解了目标，模型也可能沿着错误路线执行得非常完整。

这也解释了为什么重试有时能得到更好的答案，却不代表模型已经学会。重新采样只是回到某个分叉口，换了一条路径；模型参数没有因为上次失败自动改变。

而外部验证之所以重要，是因为它能从生成路径之外检查事实。让模型只根据自己刚写出的内容继续判断，很容易得到一段前后一致、起点却是错的答案。

下次别只看最后一句

主流大模型的生成过程可以压成一句话：

每个 Token 既是这一步的结果，也是下一步的条件。

这张图可以解释很多表面上不同的现象：

为什么相同问题会得到不同回答
为什么换个开头，整段语气都会改变
为什么错误会越说越完整
为什么计划能约束后续生成
为什么重试可能有用，却不等于学习

所以，看到一段漂亮答案时，除了检查最后的结论，还可以追问：

它是从哪一步开始走上这条路的？

模型的能力不只体现在最后选中了哪些词，也体现在一连串选择怎样把它带到了这里。
