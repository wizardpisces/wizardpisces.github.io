AI 为什么没把你写进答案？从一句产品推荐读懂 GEO

假设我做了一款代码审查工具，叫 PatchPilot。

官网已经上线，搜索产品名也能找到。首页写着：

下一代智能代码审查平台
帮助团队更快交付高质量代码

但当用户问 AI：

我们是一个 20 人的 GitLab 团队，代码不能出内网，想自动审查 Merge Request，有哪些工具适合？

AI 推荐了三款竞品，没提 PatchPilot。

页面明明存在，为什么没被写进答案？

这就是 GEO（Generative Engine Optimization，生成式引擎优化）出现的背景。

PatchPilot 是一个虚构产品。下面只追踪一句本来可能出现、最后却消失了的产品推荐。

一句话，先被拆成几个问题

用户只问了一句话，里面其实有四个条件：团队不大、使用 GitLab、代码不能出内网、需要自动审查 Merge Request。

AI 搜索不一定拿整句话只搜一次。它可能拆出几次更具体的查询：

GitLab AI code review tools
self-hosted AI code review
GitLab merge request automatic review
AI code review pricing small team
AI code review source code privacy

这些不是平台真实日志，只是对 Query 拆分的简化。它的作用是把一个模糊的“推荐什么”，拆成平台、部署、功能、成本和数据边界几个可以分别寻找证据的问题。

搜索完成后，AI 再把找到的材料拼回一段答案。如果它决定推荐 PatchPilot，可能会写：

PatchPilot 支持 GitLab Merge Request 自动审查，可以私有化部署；
它按活跃开发者收费，并且只读取当前 Merge Request Diff。

这句话正好回应了前面拆出的几个条件：平台、功能、部署方式、成本和数据范围都有了着落。

回头看 PatchPilot 的首页，它能支撑哪一个？

一个也不能。

“下一代”“智能”“更快”可以做宣传，却不能证明产品支持什么平台、怎样部署，又会读取哪些数据。

所以 PatchPilot 缺的不是更多品牌介绍，而是能让 AI 写出这句话的证据。

主张：支持私有化部署
        ↓
证据：部署方式、系统要求、外部依赖
        ↓
来源：产品文档或部署说明

这也是 GEO 最容易被忽略的地方：生成答案时，真正被挑选的不只是网页，而是网页里能够支撑某句话的内容。

竞品能进入答案，并非 AI 更喜欢它，而是它的文档回答了拆出来的问题。

问题找到了。我们重写 PatchPilot 的首页：

PatchPilot 是一款面向 GitLab 团队的 Merge Request 代码审查工具。

它读取当前 Merge Request 的 Diff，生成审查意见，
并以 GitLab Comment 的形式写回。

支持 SaaS 和私有化部署。
按活跃开发者收费，具体套餐见价格说明。
所需权限、数据保留时间和部署要求见对应文档。

下面再放上部署文档、权限清单和价格说明。

这里没有特殊的“AI 文风”，也没有刻意堆关键词。只是把空泛评价换成事实，再让事实有地方可以核验。

把 PatchPilot 放回完整流程

到这里，先把刚才发生的事放回完整链路：

网页发布 → 抓取 → 收录 ──┐
                         ├→ 检索候选 → 选择证据 → 生成答案与引用
用户问题 → Query 拆分 ───┘

PatchPilot 沿着上面那条路进入候选；“GitLab、内网部署、MR 审查、成本”沿着下面那条路变成检索条件。两条路在候选检索处汇合。

旧页面并没有消失在搜索环节。它真正掉队的地方是“选择证据”：页面被找到了，却没有一句内容能支撑那条推荐。

这也说明了 SEO 和 GEO 的关系：

SEO 主要把页面送进候选
GEO 继续争取让其中的主张进入答案

两者的边界有重叠，GEO 也离不开抓取、收录和检索。变化在于，内容竞争从“网页排在哪里”，继续延伸到“哪条主张会被写进答案”。

所以 GEO 不是让 AI “相信”某个品牌。它是在提高一条真实主张被检索、被选作证据，并被准确写进答案的机会。

生成答案以后呢？

页面重新抓取后，我们再问一次。假设这次 AI 写出了最开始缺失的那句话，并引用了 PatchPilot 的部署文档。

看起来链路走通了，但这只是一轮结果。

第一次提到，第二次没提；换个问法，又把 PatchPilot 说成了免费云服务。生成答案会波动，一张成功截图说明不了什么。怎样用固定问题、重复采样和对照实验量化 GEO，是接下来的工程问题。

但沿着这条流程再追问一步：候选来源由谁提供，证据由谁选择，答案又由谁组织？

过去，搜索引擎决定链接排在第几位，用户自己打开网页判断；现在，AI 会先选择材料，再替用户组织结论。谁控制候选来源、引用方式和答案表达，谁就在重新分配品牌与内容的可见性。

Google 的索引优势还剩多少？ChatGPT 这样的答案入口又拿走了什么？这场竞争表面上发生在搜索框里，更深处争的是“谁来组成最终答案”。

这已经不只是 GEO 的优化技巧，而是搜索正在发生的变局。
